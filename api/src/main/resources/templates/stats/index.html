운영 지표

회차와 회원 조건으로 좁혀 봅니다. 관리자 계정은 세지 않습니다. 성별·생년월일은 본인인증 전이라 회원이 입력하거나 소셜 로그인에서 받은 값입니다.

초기화

고른 날이 속한 주(월~일)에 가입한 회원만 셉니다.

유저 현황

매칭 유형 조건은 이 장에 걸리지 않습니다. 탈퇴 후 30일이 지나 완전히 삭제된 회원은 셀 수 없습니다.
