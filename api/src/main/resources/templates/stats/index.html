매칭

매칭은 성사를 뜻합니다. 1:1 은 신청이 수락된 두 사람, 그룹은 3명 이상 모인 그룹을 수락한 사람입니다. 후보는 매칭 배치가 후보를 보여 준 회원이고, 미매칭은 퀴즈를 끝까지 풀었지만 성사되지 않은 회원입니다. 배치는 목요일 00:01 에 돌아서 그 전에는 후보·성사가 0 입니다.

이 회차에 퀴즈를 끝까지 푼 회원이 없습니다.
