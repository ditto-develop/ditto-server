더미 생성

선택한 퀴즈셋을 무작위 답으로 끝까지 푼 더미를 남녀 인원수만큼 생성합니다. 매칭 후보는 만들지 않으니, 생성한 뒤 '매칭 실행'에서 매칭을 재생성하세요.

더미는 이성을 원하도록 만들어서 1:1은 남녀를 함께 생성해야 후보가 생깁니다. 그룹은 성별과 상관없이 3명 이상이면 후보가 생깁니다.

더미 직접 만들기

닉네임, 프로필, 문항별 답을 골라서 더미를 만듭니다. 특정 회원과의 매칭 점수를 조절하거나 퀴즈를 덜 푼 더미가 필요할 때 쓰세요.

퀴즈셋이 없습니다. 퀴즈셋을 먼저 만드세요.

더미 정리

현재 더미 0명. 닉네임이 dummy-로 시작하는 더미와 그 진행·답·매칭 후보를 모두 삭제합니다.

더미가 한 명이라도 낀 채팅방·1:1 매칭·그룹은 통째로 삭제합니다. 같은 방·그룹 실회원의 메시지, 이 방·매칭에 걸린 실회원의 알림·평가·재매칭, 더미가 낀 신고·회원 차단·제재도 함께 삭제합니다. 더미 신고로 실회원에게 걸린 경고·이용 정지·영구 차단도 지우고 그 회원 상태를 원래대로 되돌립니다.

실회원 쪽에서 확인할 것: 제재 관리에서 직접 건 제재는 지우지 않아 그대로 남습니다. 정지·차단이 풀린 테스트 계정은 앱에서 다시 로그인해야 합니다.
