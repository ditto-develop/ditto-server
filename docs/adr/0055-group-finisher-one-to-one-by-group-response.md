# ADR 0055 — 그룹 완주자의 1:1 응시는 그룹 응답을 기다리는지로 정한다

- 상태: Accepted (2026-11-19)
- 근거: 기획 IMP-2 시크릿 매칭 v0.2 변경 이력(D-2), 이슈 #393

## Context

[ADR 0053](0053-late-one-to-one-submission-for-secret-matching.md)은 그룹 완주자가 성사된 그룹에 수락하지 않았으면 그룹 응답 마감(금 00:00)부터 1:1 을 풀 수 있게 했다. 금 00:00 전에는 수락이 더 들어와 그룹이 성사될 수 있기 때문이다.

그런데 후보 그룹을 아예 받지 못한 사람과 초대를 거절한 사람은 그룹이 성사될 일이 없다. 이 사람들도 목요일 하루를 기다려야 했고, 홈 카드도 그동안 비어 있었다. 기획 v0.2는 그룹 화면이 응답 대기가 아니라 빈 상태면 바로 1:1 을 풀 수 있게 바꿨다.

## Decision

그룹 완주자가 그 주 그룹 셋에서 어디쯤 있는지(`GroupMatchingStatus`)로 정한다.

| 상태 | 1:1 응시 |
|---|---|
| 셋에 후보 그룹은 있는데 내 그룹이 없음, 거절 | 바로 |
| 셋에 후보 그룹이 하나도 없음, 아직 응답 전, 수락하고 성사 대기 | 그룹 응답 마감(금 00:00)부터 |
| 수락한 그룹이 성사됨(채팅방을 나갔어도) | 대상 아님 |

- 그룹 배치가 끝났다는 기록이 따로 없어서, 그 셋에 후보 그룹이 하나라도 있으면 끝난 것으로 본다. 시각(목 00:01)으로 보면 배치가 도는 사이나 실패 뒤 재시도에서 1:1 을 낸 사람이 그룹 초대까지 받을 수 있다.
- 아직 응답하지 않은 사람은 기다린다. 화면에 후보 그룹이 떠 있어 빈 상태가 아니고, 1:1 을 원하면 거절하면 된다. 금 00:00에는 어차피 자동 거절된다.
- 제출 검사(`QuizProgressService`)와 홈 카드(`SecretMatchingCard`)가 같은 `canTakeOneToOne`을 쓴다. 카드는 보이는데 제출은 막히는 일을 막기 위해서다.
- `SECRET_MATCHING` 플래그가 꺼져 있으면 지금처럼 4005로 막는다.

## Consequences

- 얻음: 후보 그룹이 없거나 거절한 그룹 완주자가 목요일부터 1:1 을 풀어 금 20:00 라운드에 들어간다.
- 비용: 셋 전체가 0그룹이면(그룹 완주자 3명 미만) 배치 전과 구분되지 않아 금 00:00까지 기다린다.
- 비용: 한 회원이 같은 주에 두 유형을 완주하는 때가 금요일에서 목요일로 당겨진다. 응답 기간(월~수)에는 여전히 진행 기록이 하나라 `quiz-progress/current`는 영향이 없다.
- 후속: 그룹 셋 NO_MATCH 알림은 그룹 노매칭자가 금요일부터만 1:1 을 풀 수 있어서 기존 문구로 두었다. 이제 바로 풀 수 있으니 시크릿 매칭 안내 문구로 바꿀지 기획 문구를 받아 정한다.
