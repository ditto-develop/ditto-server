# ADR 0055 — 그룹 완주자의 1:1 응시 시점은 그 주 그룹 상태로 정한다

- 상태: Accepted (2026-11-19)
- 근거: 기획 IMP-2 시크릿 매칭 v0.2 변경 이력(D-2), 이슈 #393

## Context

[ADR 0053](0053-late-one-to-one-submission-for-secret-matching.md)은 그룹 완주자가 성사된 그룹에 수락하지 않았으면 그룹 응답 마감(금 00:00)부터 1:1 을 풀 수 있게 했다. 금 00:00 전에는 수락이 더 들어와 그룹이 성사될 수 있기 때문이다.

그런데 후보 그룹을 받지 못한 사람과 초대를 거절한 사람은 그룹이 성사될 일이 없다. 이 사람들도 목요일 하루를 기다려야 했고, 홈 카드도 그동안 비어 있었다. 기획 v0.2는 그룹 화면이 응답 대기가 아니라 빈 상태면 바로 1:1 을 풀 수 있게 바꿨다.

## Decision

응답 마감(수 23:59:59) 뒤 1:1 제출은 그룹 완주자가 그 주 그룹 셋에서 어디쯤 있는지(`GroupMatchingStatus`)로 정한다.

| 상태 | 1:1 응시 |
|---|---|
| `NOT_INVITED` 셋에 후보 그룹은 있는데 내 그룹이 없음, `DECLINED` 초대를 모두 거절 | 바로 |
| `NO_CANDIDATE_GROUPS` 셋에 후보 그룹이 하나도 없음, `NOT_RESPONDED` 아직 응답 전, `WAITING_FOR_GROUP` 수락하고 성사 대기 | 그룹 응답 마감(금 00:00)부터 |
| `JOINED_GROUP` 수락한 그룹이 성사됨(채팅방을 나갔어도) | 대상 아님 |

- 그룹 배치가 끝났다는 기록이 따로 없어서, 그 셋에 후보 그룹이 하나라도 있으면 끝난 것으로 본다. 목 00:01이 지났는지로 판단하면, 배치가 도는 사이나 실패 뒤 재시도 중에 1:1 을 낸 사람이 그룹 초대까지 받을 수 있다.
- 아직 응답하지 않은 사람은 기다린다. 화면에 후보 그룹이 떠 있어 빈 상태가 아니고, 1:1 을 원하면 거절하면 된다. 금 00:00에는 어차피 자동 거절된다.
- 응답 기간(월~수)에는 그룹 상태와 상관없이 지금처럼 한 주 한 유형만 받는다. 응답 기간에 그룹 셋을 다시 만들면 후보 그룹이 생겨 `NOT_INVITED`·`DECLINED`가 나올 수 있어서다.
- 제출 검사(`QuizProgressService`), 홈 카드(`SecretMatchingCard`), 매칭 현황 API 의 그룹 플래그(`MatchingStatusService`)가 같은 상태를 쓴다. 카드나 그룹 화면은 1:1 을 풀라는데 제출이 거절되는 일이 없게 하려고다.
- `SECRET_MATCHING` 플래그가 꺼져 있으면 지금처럼 `QUIZ_OTHER_TYPE_ALREADY_COMPLETED`(4005)로 막는다.

## Consequences

- 얻음: 후보 그룹을 받지 못했거나 초대를 거절한 그룹 완주자가 목요일부터 1:1 을 풀어 금 20:00 라운드에 들어간다.
- 비용: 셋에서 후보 그룹이 하나도 안 나오면(그룹 완주자 3명 미만) 배치 전과 구분되지 않아 금 00:00까지 기다린다.
- 비용: 한 회원이 같은 주에 두 유형을 완주하는 때가 금요일에서 목요일로 당겨진다. 응답 기간에는 여전히 진행 기록이 하나라 `quiz-progress/current`는 영향이 없다.
- 비용: 목요일에 어드민이 그룹 셋을 다시 만들면, 이미 1:1 을 푼 사람이 새 그룹에 들어가 금 00:00 전에 수락할 수 있다. 그러면 그룹 성사와 시크릿 1:1 후보를 함께 가진다. 다시 만드는 일은 배치가 실패했을 때뿐이라 막지 않는다. 목요일에는 그룹 셋을 다시 만들지 않는다.
- 후속: 그룹 셋 NO_MATCH 알림 문구는 금요일부터 1:1 을 풀 수 있다는 전제로 그대로 두었다. 이제 목요일에 풀 수 있으니 시크릿 매칭 안내로 바꿀지는 기획 문구를 받아 정한다.
