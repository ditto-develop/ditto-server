# ADR 0053 — 시크릿 매칭을 위해 마감 뒤 1:1 응시를 토 20:00까지 받는다

- 상태: Accepted (2026-11-15)
- 근거: 기획 IMP-2 시크릿 매칭 v0.1(D-1·D-2), 이슈 #379

## Context

디토는 월~수 퀴즈 → 목 00:01 매칭 → 금~일 대화로 돈다. 목~일 신규 가입자, 월~수 미참여자, 그룹 미성사자는 다음 주 월요일까지 할 일이 없다. IMP-2 는 금·토 20:00 에 1:1 추가 라운드(시크릿 매칭)를 돌려 그 주 안에 1:1 기회를 한 번 더 준다. 라운드에 들어가려면 응답 마감(수 23:59:59) 뒤에도 1:1 퀴즈를 풀 수 있어야 한다.

전제(#377): 완주 시각 `quiz_progress.completed_at`을 서버 시각으로 남기고, 정규 매칭 풀과 마감 통계는 `isCompletedOnTime(endDate)`인 사람만 넣는다. 그래서 늦게 완주한 사람은 정규 매칭·통계에 섞이지 않는다.

## Decision

- `SECRET_MATCHING` 플래그가 켜져 있으면 이번 주 활성 1:1 셋은 응답 마감 뒤부터 토 20:00 전까지 답 제출과 문항 조회를 받는다. 토 20:00 부터 그 주 일요일까지는 둘 다 `QUIZ_SECRET_MATCHING_CLOSED`(4007)로 거절하고, 거절된 답은 저장하지 않는다. 그 전에 낸 답은 진행 중으로 남긴다. 구간 판단은 `QuizSubmissionWindow` 한 곳, 기준은 서버 시각이다.
- 그룹을 완주했어도 성사된 그룹에 수락하지 않았으면 그룹 응답 마감(금 00:00)부터 1:1 을 풀 수 있다. 금 00:00 전에는 수락이 더 들어와 그룹이 성사될 수 있어서 미성사가 정해지지 않는다. 그룹 답·진행은 지우지 않는다. 성사 그룹에 수락했다면 채팅방을 나갔어도 대상이 아니다.
- 플래그가 꺼져 있으면 제출 검사 순서(요일 → 제재 → 문항 → 기간)와 오류 코드가 그대로다. 켜져 있을 때만 셋을 먼저 읽어 늦은 응시인지 본다.

## Consequences

- 얻음: 월~수를 놓친 회원이 그 주 안에 1:1 을 풀 수 있다. 정규 매칭·통계는 늦은 완주에 흔들리지 않는다.
- 감수한 것: 한 회원이 같은 주에 그룹·1:1 을 둘 다 완주할 수 있다. "그 주 진행 기록은 하나" 를 전제로 한 집계(어드민 유형별 참여, 퀴즈 기록의 참여 주 수, 프로필 "나와 같은 답" 기준 셋)는 IMP-2 후속 작업에서 맞춘다. `quiz-progress/current`는 응답 기간 셋만 보므로 둘 이상 오류에 걸리지 않는다.
- 감수한 것: 플래그가 켜져 있으면 셋을 먼저 읽어서, 없는 문항 ID 를 목요일에 보내면 4004 대신 404 가 나는 식으로 오류 우선순위가 달라진다.
- 늦게 완주한 회원은 마감 통계 스냅샷에 들지 않아, 지금 퀴즈 기록 상세에서 겹친 사람·소수 의견이 0 으로 나온다. 표시는 IMP-2 화면 API 작업에서 정한다.
- **플래그는 아직 켜지 않는다.** 켜기 전에 필요한 것: 시크릿 라운드(금·토 20:00 후보 선발), 어드민 참여 현황의 늦은 완주자 분류, 늦은 구간에 1:1 셋을 알려 주는 홈 상태 API(`quiz-sets/current-week`·`quiz-progress/current`는 목~일에 비어 있다), FE 연동. 목~일 그룹 셋 제출(4004)·셋 조회(4001)가 ERROR 로 남는 것도 켜기 전에 WARN 으로 내릴지 정한다.
