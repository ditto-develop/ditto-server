# ADR 0048 — 가입 이탈 장의 회원 목록은 가입 진행 정보까지 내린다

- 상태: Accepted (2026-10-28)
- 근거: code-evidence (#358)

## Context

운영 지표에 가입 이탈 장을 따로 둔다(#358). 가입을 시작하고 마치지 못한 회원과, 가입은 했지만 소개노트가 모자라 퀴즈를 못 하는 회원을 운영자가 직접 챙겨 볼 수 있어야 한다.

[ADR 0047](0047-admin-stats-member-lists.md)은 목록에 회원 id·닉네임·건수만 내리고, 넘기려면 새 ADR 이 필요하다고 정했다. 이 두 목록은 누가 어디서 멈췄는지가 보여야 쓸모가 있다.

## Decision

- 가입 이탈 목록은 회원 id, 가입 시작 시각, 로그인 수단, 멈춘 단계(닉네임 예약 유무), 푸시 기기 유무를 내린다. 가입 중인 회원의 닉네임은 임시값이라 내리지 않고 id 로 회원 검색에 연결한다.
- 퀴즈를 못 하는 회원 목록은 회원 id, 닉네임, 가입 완료 시각, 소개노트 수, 퀴즈 시작 여부를 내린다.
- 두 목록 모두 인원 제한 없이 전부 내리고 카드 안에서 스크롤한다.

## Consequences

- 가입 시각·로그인 수단은 회원 관리 화면에 없던 값이라 어드민이 보는 범위가 그만큼 넓어진다. 둘 다 그것만으로는 누구인지 알 수 없는 값이라 받아들인다. 이메일·생년월일·소개노트 내용은 여전히 내리지 않는다.
- 푸시 기기는 있다/없다만 내리고 토큰은 내리지 않는다.
- 가입 이탈이 많이 쌓이면 목록이 길어진다. 페이지 크기가 문제가 되면 그때 상한을 둔다.
