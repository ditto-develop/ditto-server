# ADR 0052 — 1:1·재매칭 방에서는 상대의 문항별 답을 보여 준다 (ADR 0020 갱신)

- 상태: Accepted (2026-11-04)
- 근거: 기획 IMP-1(퀴즈 기록·대화방 답변 비교) + 리뷰 결정(서버 위키 `IMP-1-Quiz-History-Answer-Compare` §0)

## Context

[ADR 0020](0020-peer-profile-answer-match-summary.md)은 타인 프로필에 상대의 선택지를 주지 않고 일치 요약(개수·비율)만 주기로 했고, "문항별 비교표 같은 UI 가 생기면 계약을 다시 연다"고 적었다. IMP-1 의 대화방 '우리의 답변'(CH-01·02)이 바로 그 UI 다 — 같은 답·다른 답을 문항별로 나눠 보여 주고, 그 문항으로 말을 걸게 한다.

그룹 방(CH-03·04)은 "누가 어떤 답을 골랐는지는 보이지 않아요"가 화면 원칙이다.

## Decision

- **`GET /api/v1/chat/rooms/{roomId}/quiz-compare`에 한해** 상대의 문항별 선택(`peerChoiceId`)을 준다. 대상은 두 사람 방(`PERSONAL`·`REMATCH`)이고, 재매칭 방은 원래 그룹 퀴즈(`rematch.quiz_set_id`)가 기준이다.
- 노출 기간은 **방이 생긴 뒤부터 채팅이 끝나기 전까지**다. 끝난 방은 `CHAT_ROOM_ENDED`(7004)로 막는다 — 기획서의 "종료 후 열람 가능"과 반대다(위키 §0-3).
- 상대가 탈퇴했거나 어느 쪽이든 차단했으면 `QUIZ_COMPARE_UNAVAILABLE`(7008)로 막는다. 차단 화면 문구("나의 프로필을 볼 수 없고")와 같은 결이다.
- 그룹 방은 `GET /quiz-distribution`으로 **선택지별 인원 수만** 준다. 멤버 ID·닉네임과 선택을 잇는 필드는 없다. 소수 인원에서 유추되는 것은 허용한다(위키 §0-2).
- 질문 카드도 같은 원칙이다. 1:1 카드는 두 사람의 선택을 싣고, 그룹 카드는 인원 수만 싣는다(보낸 사람의 선택도 넣지 않는다).
- 타인 프로필(`GET /users/{id}/answers`)은 ADR 0020 그대로 일치 요약만 준다.

## Consequences

- 얻음: 매칭된 두 사람이 대화를 시작할 재료를 문항 단위로 얻는다.
- 감수한 것: 매칭 상대에게 내 문항별 답이 보인다. 매칭 기간 동안 대화 상대에게만, 방이 끝나면 다시 닫힌다. 개인정보 처리방침상 "매칭 상대에게 퀴즈 답이 공개된다"는 고지가 필요한지는 기획 확인 대상이다(FE 요청서 확인 (4)).
- ADR 0020 의 "비용" 항목(문항별 비교표를 만들려면 계약을 다시 연다)이 이 ADR 로 해소된다. 0020 은 프로필 경로의 결정으로 유지된다.
