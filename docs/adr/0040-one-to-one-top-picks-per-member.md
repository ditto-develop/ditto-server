# ADR 0040 — 1:1 후보는 회원마다 상위 5명을 고르고 한쪽만 골라도 남긴다

- 상태: Accepted (2026-10-09)
- 근거: discussion (#293)

## Context

1:1 후보는 자격 페어(성별 선호·나이 차·차단)를 점수로 줄 세운 뒤 두 단계로 걸렀다. 풀 전체에서 점수 상위 20%만 남기고, 그중 양쪽 모두의 상위 5명에 든 페어만 남겼다([ADR 0007](0007-matching-pure-pipeline.md)).

이 방식에서는 자격 상대가 있어도 후보가 0명인 사람이 생긴다. 0명이 생기는 길은 둘이다.

- 상위 20% 컷: 내 페어가 모두 풀 전체 상위 20% 밖이면 빠진다. 인원이 적을수록 심하다.
- 양방향 5명 제한: 점수는 대칭이어도 순위는 아니다. 남들과 두루 점수가 낮은 사람은 상대마다 자기보다 잘 맞는 사람이 5명 넘게 있어서, 내가 고른 상대가 아무도 나를 고르지 않는다. 인원이 많을수록 상대 한 명이 남기는 비율이 줄어 이쪽이 늘어난다.

답을 무작위로 만든 시뮬레이션(문항 10개, 선택지 2개)에서 0명 비율은 남녀 5:5일 때 10명 약 20%, 100명 약 3%였다. 남녀 7:3이면 100명 이상에서 약 11%였다. 매칭의 의도는 0명인 사람을 최대한 없애는 것이다.

검토한 대안은 다음과 같다.

- 20% 컷만 없앤다: 인원이 적을 때는 0명이 사라지지만 40명을 넘으면 양방향 5명 제한 때문에 그대로 남는다.
- 0명인 사람에게만 상대를 붙인다: 1명만 붙이면 보장이 1명뿐이다. 5명까지 붙이면 0명이던 사람이 겨우 1명 남은 사람보다 많이 받는 역전이 생긴다.
- 컷과 제한을 모두 없앤다: 0명은 사라지지만 후보가 자격 있는 이성 전원이 된다. 후보 관계가 소개노트를 성사 전에 볼 수 있는 근거라([ADR 0025](0025-intro-note-candidate-preview.md)) 공개 범위까지 넓어진다.

## Decision

상위 20% 컷을 없앤다. 회원마다 자격 페어를 점수 높은 순으로 5개 고르고, 둘 중 한 명이라도 고른 페어는 남긴다(`TopPicksSelector`). 동점은 지금처럼 섞은 뒤 stable 정렬해서 무작위로 자른다.

자격 상대가 있는 회원은 자기가 고른 페어가 남으므로 0명이 되지 않는다. 자격 상대가 5명 이상이면 최소 5명, 그보다 적으면 상대 전원을 받는다.

## Consequences

- 얻음: 후보 0명은 자격 상대가 아예 없는 회원뿐이다. 점수가 낮다고 빠지는 사람이 없다. 동점 무작위가 누가 후보를 받는지에 영향을 주지 않아서, 어드민의 "후보가 없는 이유"를 무작위 없이 정확히 계산한다.
- 비용: 5명은 상한이 아니다. 여러 사람에게 뽑힌 회원은 5명을 넘게 받는다. 같은 시뮬레이션에서 남녀 5:5면 평균 약 7명, 가장 많은 사람이 10~15명이었다. 남녀 7:3이면 적은 쪽이 평균 약 12명, 많으면 20명 넘게 받는다. 내 후보 중에는 상대가 나를 상위 5명으로 고르지 않은 사람도 섞인다.
- 후속/연쇄: 후보 조회 API 응답 형태는 그대로이고 개수만 늘어난다. FE 후보 화면이 5명 넘는 목록을 그리는지 확인해야 한다. 어드민 "후보가 없는 이유"에서 상위 비율 컷과 후보 수 한도 이유가 빠졌다.
